# Lab 07 – Model Evaluation

## Overview
In this lab, I focused on evaluating machine learning models to determine how well they perform on data.

## What I Did
I worked with model evaluation techniques and examined performance measurements used to compare predictions with actual outcomes.

## What I Learned
I learned that training a model is only part of the machine learning process. A model also needs to be evaluated to determine whether it performs well on data it has not simply memorized. Evaluation metrics provide a more objective way to compare models and identify areas for improvement.

## Challenges
One challenge was understanding what the different evaluation measurements represented and when they should be used. The lab helped me connect the metrics to the actual performance of a model.
