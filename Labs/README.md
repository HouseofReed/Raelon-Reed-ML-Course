# Machine Learning Labs

This folder contains the hands-on laboratory exercises I completed throughout my Machine Learning course.

These labs allowed me to practice the machine learning concepts covered throughout the course using Python and Jupyter Notebooks. Topics include data exploration, data preparation, supervised and unsupervised learning, model evaluation, ensemble methods, hyperparameter tuning, responsible AI, and machine learning pipelines.

Each lab folder contains my completed Jupyter Notebook along with documentation explaining the purpose of the lab, what I learned, and any challenges I encountered.
