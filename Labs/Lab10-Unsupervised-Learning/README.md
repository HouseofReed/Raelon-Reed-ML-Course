# Lab 10 – Unsupervised Learning

## Overview
In this lab, I explored unsupervised learning and how machine learning can be used to discover patterns in data without predefined target labels.

## What I Did
I worked with unsupervised learning concepts and examined methods for identifying structure or groups within a dataset.

## What I Learned
I learned that unsupervised learning differs from supervised learning because the model is not given a known target answer during training. Instead, it attempts to identify meaningful patterns or relationships within the data.

## Challenges
One challenge was interpreting results when there was no known target value to compare against. The lab helped me understand that unsupervised learning requires looking at the structure discovered by the model and deciding whether it is meaningful.
