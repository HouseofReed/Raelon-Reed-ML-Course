# Lab 04 – Exploratory Data Analysis

## Overview
In this lab, I explored how exploratory data analysis (EDA) can be used to better understand a dataset before building a machine learning model.

## What I Did
I used Python to examine data, review its structure, identify patterns, and summarize important features of the dataset. I practiced using data analysis techniques to understand what the data was showing before moving into modeling.

## What I Learned
I learned that EDA is an important part of the machine learning process because it helps identify patterns, unusual values, missing information, and relationships within the data. This makes it easier to make better decisions about how the data should be prepared and modeled.

## Challenges
One challenge was determining which information in the dataset was most important to focus on. Working through the analysis helped me understand how different summaries and visualizations can provide useful information about the data.
