# Lab 13 – Building Machine Learning Pipelines

## Overview
In this lab, I focused on building machine learning pipelines that combine preprocessing and modeling steps into one organized workflow.

## What I Did
I worked with preprocessing steps and a trained model and examined the difference between managing these steps manually and combining them into a single pipeline.

## What I Learned
I learned that a pipeline can make a machine learning workflow safer, more consistent, and easier to reuse. Instead of requiring each preprocessing step to be applied separately, a pipeline keeps the transformations and model together so new data is processed in the same way as the training data. I also learned how this approach can help reduce mistakes and prevent data leakage.

## Challenges
One challenge was understanding why the order and timing of preprocessing steps matter. Comparing the manual approach with a pipeline made it clearer how pipelines help maintain consistency and reduce the risk of applying transformations incorrectly.
