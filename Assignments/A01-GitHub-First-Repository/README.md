# A01 – Getting Started with GitHub & Your First Repository

## Overview

The purpose of this assignment was to become familiar with GitHub and learn how repositories can be used to organize, document, and share programming and machine learning projects.

## What I Did

For this assignment, I created my first GitHub repository and practiced using GitHub to manage course files. I learned how repositories, files, folders, and README documentation can be used to keep projects organized and accessible.

## What I Learned

This assignment introduced me to GitHub as a tool for managing and presenting technical work. I learned how to create a repository, upload files, make changes, and use README files to explain the purpose and contents of a project.

I also learned the importance of keeping a repository organized and using clear documentation so that someone viewing the project can understand the work without needing additional explanation.

## Challenges

Since GitHub was new to me, one of the main challenges was learning how repositories are structured and how files and folders are managed within them. As I continued using GitHub throughout the course, I became more comfortable navigating repositories and organizing my work.

## Connection to This Portfolio

The skills introduced in this assignment were used to create this Machine Learning course portfolio. This repository demonstrates my progress in organizing my work, documenting my projects, and using GitHub to present my machine learning coursework.
